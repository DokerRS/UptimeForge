## What's new in 0.4.1

- **Addresses and operators in the antifraud message.** The message now lists the subscriber's addresses inside the window (the first 20) with the operator and ASN of each. It also gives a summary of the operators with how many addresses each, for example "MTS PJSC · 8". The *Antifraud* page shows the operator next to each address.
- **The offline GeoIP database is checked daily.** The operators come from the hub's own copy of the DB-IP Lite databases (country and ASN), so no address leaves the hub.
  - The hub looks for a newer database once a day and takes a new month's file the day DB-IP puts it out. Before, it waited until the old file was 35 days old.
  - A check that finds nothing new downloads nothing.
  - The antifraud now starts the database download itself, so a hub whose agents all sit on private addresses still gets it.

## Upgrade

```sh
docker compose pull && docker compose up -d
```

Only the hub changes.

## Русский

### Что нового в 0.4.1

- **Адреса и операторы в сообщении антифрода.** В сообщении теперь есть адреса клиента за окно (первые 20) с оператором и ASN у каждого. Ещё в нём сводка по операторам с числом адресов, например «MTS PJSC · 8». На странице *Антифрод* оператор показан рядом с каждым адресом.
- **Офлайн-база GeoIP проверяется раз в сутки.** Операторы берутся из собственной копии баз DB-IP Lite (страна и ASN) на хабе, адреса никуда не отправляются.
  - Хаб раз в сутки проверяет, нет ли базы новее, и берёт файл нового месяца в тот же день, когда DB-IP его выпустит. Раньше он ждал, пока старому файлу исполнится 35 дней.
  - Если новой базы нет, ничего не скачивается.
  - Антифрод теперь сам запускает загрузку базы, поэтому она будет и на хабе, где все агенты сидят на приватных адресах.

### Обновление

```sh
docker compose pull && docker compose up -d
```

Меняется только хаб.
