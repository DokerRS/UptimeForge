## What's new in 0.3.0

- **Any check type in *Tools*.** The single-target test has a *Check type* picker next to *Auto*. Auto works as before: it reads a share link, URL or `host:port`. Or pick any type a probe can run and fill in its fields, the same as in the check form:
  - ping, TCP port, DNS, TLS certificate;
  - HTTP(S) with a keyword or JSON query;
  - SMTP, RADIUS, databases and the rest of the catalog.

  Push and manual checks are not offered: they wait for something to reach the hub. Subscriptions keep their own mode.
- **Check from a checker agent.** Every point on the *Checker agents* page has a *Check from here* button. It opens *Tools* with that point picked, so you can test a site or a port from that operator's network. The button is off while the point is offline.
  - An untrusted point still never gets a check with a password or a VPN link.
  - Types disabled on the agent with `UF_DENY_TYPES` show as unavailable on that probe.

## Upgrade

```sh
docker compose pull && docker compose up -d
```

Only the hub changes. Agents installed by 0.2.0 or later update themselves from the hub.

## Русский

### Что нового в 0.3.0

- **Любой тип проверки в *Инструментах*.** В режиме «Один конфиг» появилось поле *Тип проверки*. «Авто» работает как раньше: понимает ссылку, URL или `host:port`. Или выберите любой тип, который умеют пробы, и заполните его поля так же, как в форме проверки:
  - ping, TCP-порт, DNS, TLS-сертификат;
  - HTTP(S) с ключевым словом или JSON-запросом;
  - SMTP, RADIUS, базы данных и остальной каталог.

  Push и ручные проверки в списке нет: они ждут события на самом хабе. У подписки остался свой режим.
- **Проверка с агента проверок.** У каждой точки на странице *Агенты проверок* есть кнопка *Проверить отсюда*. Она открывает *Инструменты* с этой точкой: сайт или порт можно проверить из сети её оператора. Пока точка офлайн, кнопка неактивна.
  - Недоверенная точка по-прежнему не получает проверки с паролем или VPN-ссылкой.
  - Типы, отключённые на агенте через `UF_DENY_TYPES`, на этой пробе показываются как недоступные.

### Обновление

```sh
docker compose pull && docker compose up -d
```

Меняется только хаб. Агенты версии 0.2.0 и новее обновятся от хаба сами.
