## What's new in 0.4.3

- **Fix: a phone behind mobile CGNAT is no longer taken for a crowd.** A mobile operator's CGNAT sends one phone out of many addresses of its pool at once, so 0.4.2 could see 20–30 live addresses for a single subscriber. Now IPv4 addresses count per /20 network. On the hub this came from, one subscriber with a device limit of 3 had 19 live addresses in 5 networks: that is under the threshold of 9 now, while subscribers whose addresses are really spread out keep their count (26 addresses in 21 networks, 12 in 11).
  - The size is set in *Settings → Remnawave → Antifraud → Count IPv4 per network*: /20 by default, "Every address" counts as before. IPv6 still counts per /64.
  - The thresholds, the hold and the "twice as many" repeat all count networks now.
- **The message gives both numbers.** For example: "/20 networks now: 5 · 28 addresses · 1.7× the limit". The address table and the operators are unchanged. The *Antifraud* page shows networks in the *Now* column with the addresses under them, and the network of each address in the subscriber's card.

## Upgrade

```sh
docker compose pull && docker compose up -d
```

Only the hub changes. Holds already running keep going, now measured in networks.

## Русский

### Что нового в 0.4.3

- **Исправлено: телефон за мобильным CGNAT больше не принимается за толпу.** Мобильный оператор через CGNAT выпускает один телефон сразу через много адресов своего пула, поэтому 0.4.2 могла насчитать у одного клиента 20–30 живых адресов. Теперь адреса IPv4 считаются по подсетям /20. На хабе, где это нашли, у клиента с лимитом 3 устройства было 19 живых адресов в 5 подсетях: теперь это ниже порога 9. У клиентов, чьи адреса действительно разбросаны, число почти не меняется (26 адресов в 21 подсети, 12 в 11).
  - Размер задаётся в *Настройки → Remnawave → Антифрод → IPv4 считать по подсетям*: по умолчанию /20, вариант «Каждый адрес отдельно» считает как раньше. IPv6 по-прежнему считается по /64.
  - Пороги, удержание и повтор при росте вдвое теперь считают подсети.
- **В сообщении оба числа.** Например: «Подсетей /20 сейчас: 5 · адресов 28 · в 1,7 раза больше лимита». Таблица адресов и операторы остались. На странице *Антифрод* в колонке *Сейчас* показаны подсети, под ними число адресов, а в карточке клиента у каждого адреса указана его подсеть.

### Обновление

```sh
docker compose pull && docker compose up -d
```

Меняется только хаб. Уже идущие удержания продолжаются, но теперь в подсетях.
