## What's new in 0.4.2

- **The antifraud message is a rich card.** It is laid out like the incident cards:
  - a heading by outcome: over the limit, would be banned, disabled, or the disable failed;
  - a table of facts: subscriber, Telegram, device limit, addresses now (and how many times the limit that is), addresses over 24 hours, nodes, and the action taken;
  - a table of operators with their address counts;
  - the addresses folded under *Addresses* (the first 30, each with its operator and ASN);
  - panel errors as a quote.

  A Bot API server without rich messages still gets the plain HTML.
- **A sample card.** The *Test* button of the *Antifraud* route in the Telegram settings sends a sample card with documentation addresses, so you can see the layout without waiting for a real case.

## Upgrade

```sh
docker compose pull && docker compose up -d
```

Only the hub changes.

## Русский

### Что нового в 0.4.2

- **Сообщение антифрода стало rich-карточкой.** Оно устроено как карточки инцидентов:
  - заголовок по итогу: превышение, был бы заблокирован, подписка отключена или отключить не удалось;
  - таблица: клиент, Telegram, лимит устройств, адресов сейчас (и во сколько раз это больше лимита), адресов за 24 часа, ноды и что сделано;
  - таблица операторов с числом адресов;
  - адреса в раскрывающемся блоке *Адреса* (первые 30, у каждого оператор и ASN);
  - ошибки панели цитатой.

  Если сервер Bot API не поддерживает rich-сообщения, уходит обычный HTML.
- **Образец карточки.** Кнопка *Тест* у маршрута *Антифрод* в настройках Telegram присылает образец карточки с документационными адресами: вид можно оценить, не дожидаясь настоящего срабатывания.

### Обновление

```sh
docker compose pull && docker compose up -d
```

Меняется только хаб.
