## What's new in 0.4.0

- **Antifraud for Remnawave.** Every minute the hub reads the open connections of every panel node and counts how many addresses each subscriber connects from at once.
  - Addresses are counted per /64 for IPv6. Node and bridge addresses and private addresses are not counted.
  - A message goes to Telegram when the count stays far over the user's device limit: at least max(limit × 3, limit + 5) addresses for 15 minutes. That is 6 addresses at a limit of 1 and 9 at a limit of 3.
  - The message has the user id, username, Telegram id, limit, addresses now and over 24 hours, the nodes and the operators. It never has the addresses themselves.
  - The message goes to its own *Antifraud* route in the Telegram settings, so it can have a topic of its own or be turned off.
- **Automatic bans are opt-in.** In *Settings → Remnawave → Antifraud*, the *Notify and ban* mode disables a user whose count holds over the ban threshold (by default max(limit × 5, limit + 10) for 30 minutes), then closes its connections.
  - Until you turn it on, a "would be banned" message comes instead.
  - The card also sets the window, both thresholds, the repeat interval, how long addresses are kept, and the user ids and tags that are never judged.
- **The Antifraud page** (admins only) lists subscribers over a threshold and everyone with an event this week. A subscriber's card shows its addresses, nodes and history, with *Allowlist* and *Unban* buttons.
- **No false shortcuts.** Time with the hub down, the antifraud off or the panel unreachable never counts towards a hold. A poll that missed some nodes does not reset one. A user the panel's directory does not know yet is never banned.

The hub reads only the id, username, Telegram id, status, tag and device limit of panel users. The credentials in the user objects are never read.

## Upgrade

```sh
docker compose pull && docker compose up -d
```

Only the hub changes. The antifraud starts in notify mode with the defaults. To keep it quiet, set the mode to *Off* in *Settings → Remnawave → Antifraud*, or turn the *Antifraud* route off in the Telegram settings.

## Русский

### Что нового в 0.4.0

- **Антифрод для Remnawave.** Раз в минуту хаб читает открытые подключения на всех нодах панели и считает, со скольких адресов одновременно сидит каждый клиент.
  - IPv6 считается по /64. Адреса нод и мостов и приватные адреса не считаются.
  - Сообщение в Telegram приходит, когда число адресов держится намного выше лимита устройств: не меньше max(лимит × 3, лимит + 5) в течение 15 минут. Это 6 адресов при лимите 1 и 9 при лимите 3.
  - В сообщении id, username, Telegram id, лимит, число адресов сейчас и за 24 часа, ноды и операторы. Самих адресов в нём нет.
  - Сообщения идут в отдельный маршрут *Антифрод* в настройках Telegram: ему можно дать свою тему или выключить его.
- **Автоблокировка включается отдельно.** В *Настройки → Remnawave → Антифрод* режим *Уведомлять и блокировать* отключает клиента, у которого число адресов держится выше порога блокировки (по умолчанию max(лимит × 5, лимит + 10) в течение 30 минут), и обрывает его подключения.
  - Пока режим не включён, вместо блокировки приходит сообщение «был бы заблокирован».
  - В той же карточке настраиваются окно, оба порога, частота повторов, срок хранения адресов, а также id пользователей и теги, которых антифрод не трогает.
- **Страница «Антифрод»** (только для админов) показывает клиентов выше порога и всех, по кому были события за неделю. В карточке клиента его адреса, ноды и история, кнопки *В белый список* и *Разблокировать*.
- **Без ложных срабатываний.** Время, пока хаб лежал, антифрод был выключен или панель не отвечала, в удержание не засчитывается. Опрос, в котором ответили не все ноды, удержание не сбрасывает. Пользователя, которого ещё нет в справочнике панели, антифрод не заблокирует.

Из пользователей панели хаб читает только id, username, Telegram id, статус, тег и лимит устройств. Учётные данные из объекта пользователя не читаются.

### Обновление

```sh
docker compose pull && docker compose up -d
```

Меняется только хаб. Антифрод сразу работает в режиме уведомлений с настройками по умолчанию. Чтобы он молчал, выберите режим *Выключен* в *Настройки → Remnawave → Антифрод* или выключите маршрут *Антифрод* в настройках Telegram.
